KT Ultra Morph  ——  K5 三模型定制版
============================================

【本包内容】
内置以下三个 K5 音色模型，开箱即用：

    · 史诗小柒K5
    · 初雪K5
    · 典藏酸奶K5

【运行环境】
    - Windows 10 / 11 64 位
    - NVIDIA 独立显卡（建议 6GB 以上显存）
    - 首次运行需要管理员权限（用于本地服务配置）

【使用方法】
    1. 双击 ktum.bat 启动
       （弹出权限请求时点"是"）
    2. 等待自动配置完成（约 10 秒）
    3. 在主界面选择模型 → 点击"使用"
    4. 在虚拟声卡中选择对应通道即可开始

【停止程序】
    关闭主程序窗口，并关闭标题为
    "KTUM 授权服务器" 的命令行窗口

【运行自检】
    双击 check.bat，可检查各项服务状态

【卸载清理】
    双击 uninstall.bat 还原系统配置，
    之后直接删除本文件夹即可

【常见问题】

    Q: 提示无法连接授权服务？
    A: 确认 "KTUM 授权服务器" 窗口没有被关闭。
       如果已关闭，重新运行 ktum.bat 即可。

    Q: 换到别的电脑能用吗？
    A: 可以。首次在每台电脑上运行一次 ktum.bat，
       完成本机配置后即可正常使用。

    Q: 模型列表里为什么只有三个模型？
    A: 本包为定制版本，仅内置上述三个音色。
       需要其他音色请通过下方方式联系。

    Q: 运行时提示显存不足？
    A: 关闭其他占用显卡的程序；显存建议 6GB 以上。
